# Greenlab per-fort charter template (P3)

**Install-ready founding artifact.** The template for an individual Greenlab
experiment fort's charter — the low-stakes variant of the production charter. A
Greenlab fort is *an experiment* (or a small cluster of related ones); this is its
constitution. `{{...}}` slots are filled by fort-init / the founding moot.

## The distinction from the covenant

- The **covenant** (`covenant.md`) is civilization-wide law: the machine boundary,
  the seats, the governors, the human gates, the graduation decision. It does not
  change per fort.
- This **charter** is one experiment fort's own constitution: its purpose, its
  specific loss bound and channels, its gates as they apply to *this* experiment.
  It is deliberately thin, because a Greenlab fort's charter protects a throwaway
  experiment, not a customer — the heavy law lives in the covenant, and a single
  experiment fort's charter can be nearly disposable.

The production charter is ~4,500 words because it protects paid work. A Greenlab
fort charter should be short. If it grows long, that is a signal the experiment
has outgrown Greenlab and the Overseer should consider graduating it (covenant
standing order 8).

### Experiment charter (the self-feeding Mayor reads this)

- **Hypothesis / segment / offer:** {{WHAT WE ARE TESTING, FOR WHOM}}
- **The decision this experiment could change:** {{STOP / SCALE / PIVOT}}
- **Loss bound:** {{PER-EXPERIMENT LOSS BOUND}} — reserved before the first paid
  action (covenant §7). Reaching it stops the experiment; it does not overspend.
- **Allowed channels / providers:** {{THE STANDING GRANT — where this experiment
  may act outward}}. Anything outside this list is a gate (covenant §6).
- **Make-whole reserve:** {{HELD IF THIS EXPERIMENT TAKES A PAYING CUSTOMER}} —
  never spent on new work (covenant §7, §8).
- **Maturity window:** {{HOW LONG BEFORE AN OUTCOME IS TRUSTED}} — the `OBSERVING`
  state's deadline; a bead waiting on this is waiting, not stalled.

### Gates, as they apply here

The covenant's four human gates (§6) apply unchanged. This fort names any
experiment-specific instance:

- Spend above {{THIS EXPERIMENT'S CEILING}} → gate 1.
- Any new external identity for this experiment → gate 2.
- Irreversible actions above {{THRESHOLD}} → gate 3.
- Graduation of this experiment → gate 4, the Overseer's alone.

### Reviewer posture

The Warden is a **tripwire** here (covenant §5): it reviews after merge and
announces. It becomes a **gate** only for changes on this experiment's spend /
identity / money path. The deterministic verifier carries the load-bearing claim
for ordinary work.

### Standing orders

The covenant's standing orders (§9) apply. No fort-specific standing order is added
unless this experiment earns one by an observed failure (the production rule:
infrastructure requires an observed failure, not an imagined one). A Greenlab fort
should rarely need its own.

### Seats

The covenant's seats (§5) serve this fort. Occupants:
{{NAMED AT FOUNDING — placeholders may survive the identity strip}}.

### The one thing this charter must never relax

If this experiment handles money, its books reconcile against the provider
independently (covenant §11). Nothing in a per-fort charter may soften that; it is
civilization law, not fort law.

## Note for the template author

Keep this template thin on purpose. Every clause a Greenlab fort charter adds is a
clause a Greenlab experiment did not need until it did. The covenant does the
heavy lifting; this charter is the experiment's own short statement of what it is
testing, what it may spend, and where it may act. A fat Greenlab charter is a
smell — either the covenant is missing something (fix the covenant, not the
charter) or the experiment has grown up and wants graduating.
