## Item 1 was two defects and the docket described the wrong one

`ForgeOs-96bg`'s title and the docket both describe the **Mayor's** failure: gate-6
paths are read-only directory binds, so a merge whose diff touches them dies with
`unable to unlink old ...: Read-only file system`. **That is inherent.** Git rewrites
a tracked file by unlinking it; if git may write those paths, a seat may write those
paths. No mask edit fixes it without making the boundary conditional, which the bead
already rejected on sight. It breaks only merges that actually touch gate-6 paths.

The **fixable** half was in a 2026-08-28 escalation comment, not the description.
`forge.sh` masked two **TRACKED** files with `--mask-file` (a `/dev/null` bind),
making them **character devices**. Measured inside a real Forge mask before any edit:

```
scripts/deploy-azure-staging.sh    CHAR DEVICE
scripts/airlock-feedback-scan.sh   CHAR DEVICE
 M scripts/airlock-feedback-scan.sh
 M scripts/deploy-azure-staging.sh
fatal: cannot hash scripts/airlock-feedback-scan.sh
```

Worse than the bead recorded: **`git diff` itself dies**, not merely merge. And it
broke **every** worktree operation for **every** branch, not only gate-6 ones — that
is what cost the fort its main-integration lane. `15k.2` had **doubled** it by adding
the second char device.

**And it bought nothing.** From that same mask,
`git show HEAD:scripts/deploy-azure-staging.sh` returned all **13215 bytes**. You
cannot hide a tracked file from a seat that can read `.git`. The `forge.sh` header's
own rationale — "Masked to /dev/null so it reads EMPTY; an extra-ro-path would leave
it readable" — described a property the mask never had.

Fixed on the Overseer's decision: the four `--mask-file` entries become extra-ro
positionals, i.e. read-only binds of the files' own content. **What was traded is
the kernel exec block**, named in the header rather than glossed, resting on his
ruling closing `ForgeOs-hi9c` (gate 3 is an execution gate the sandbox enforces
independently). It is the first thing Tova should look at.

The inherent half is now **written down** in both seat prompts, with `skip-worktree`,
cherry-picks and hand-built trees forbidden by name.
