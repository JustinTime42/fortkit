## The correction that outlives this sitting

**The docket's THE TRAP block rests on a measurement that could not have
discriminated.** It read `dep.get('type')` off a `bd show` record, where that key
is null for EVERY edge whatever its type. Under `dependency_type` a default edge
reads back as the literal string `blocks`. bd materialises the default; it does
not record it by omission.

**And `bd show` and `bd list` use SWAPPED key names for the same field** — `show`
populates `dependency_type` and nulls `type`, `list` does the reverse and nulls
the dep's `id` as well. A guard reading the wrong one refuses every bead and
stops the fleet completely. **The fix reads both keys and takes the first
non-empty one**, pinned by a harness case. Filed `ForgeOs-v30w` (P1), linked
`discovered-from` to `czhb`. The correction is appended to `ForgeOs-czhb`; the
docket is an annal and is not edited.

**The design did not change — its reason did**, from the stated premise to
fail-closed-on-the-unknown. Saying which is which is the whole of the correction.
