**Three harness defects presented as defects in the subject before I caught
them.** The stub Forge wrote content identical to what was already committed, so

scenario read as "the Forge failed". `run_pass` set its exit code inside a

and matched **the run's own opening line, which tells the operator that touching
`$FLEET_STATE/HALT` stops it** — a control failing on the boilerplate that
explains the thing it is checking for.

against a file that was simply already narrowed. Split into
`FLEET_SH_PRE_NARROWING` and `FLEET_SH_PRE_KE5U`, each optional, each reported
